# Daily Discipline

Daily Discipline is a simple web-based habit and consistency tracker built with **HTML, CSS, and JavaScript**.

## Features

* 🎯 Set a target from **1 month to 12 months**
* 📅 **30, 60, 90 ... 360 days** targets
* 🏆 **365 Days Challenge**
* 🔒 Future days remain locked
* ✅ Complete only the current day
* 📊 Progress percentage
* 📈 Progress chart
* 🔥 Streak counter
* 🎉 Congratulations messages at milestones
* 👤 Gmail-based demo login
* 🔑 Demo password: `1234`
* 💾 Progress is saved in browser Local Storage
* 📱 Responsive design for mobile and desktop

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js
* Browser Local Storage

## How to Run

1. Download or clone the project.
2. Open the `index.html` file in a web browser.
3. Enter any Gmail address.
4. Enter password:
   `1234`
5. Select your target.
6. Start completing your daily challenge.

## Important Note

The Gmail login in this project is a **demo frontend login**. It does not perform real Google authentication.

For a production website with real user accounts and synchronized data across devices, a backend/database and secure authentication system should be added.
